## What changed from the original spec's table

- Vercel and Supabase Studio's "no fresh screenshot this session" limitation is now a **confirmed access block** (direct fetch attempted, returned a login/portal screen), not an assumed one.
- Tremor's "bento card" ban is now backed by the product's own homepage description, not inference.
- PostHog's freshness-label pattern ("Computed a few seconds ago") is newly documented — it's a closer real-world precedent for the Overview tab's "AI summary... freshness stated inline" requirement than anything in the original table.
- No new design decisions follow from this pass; the already-shipped implementation was built against the original spec's judgment calls, which this fresher evidence does not contradict.
